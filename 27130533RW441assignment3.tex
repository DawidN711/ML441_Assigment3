	\section{Introduction}
	This study tests how the performance of feed-forward neural networks (NN) change when employing active learning compared to passive learning.
	
	\section{Background}
	A feed-forward NN contains multiple layers of percetrons, where the hidden layers, between the input and output layers, enable the model to capture non-linear patterns. A single perceptron consists of input nodes and weights, and these input values with weights are combined (weighted summation or product) and then an activation function is applied to the result to produce a single output. To produce multiple outputs (for multiclass classification for example), multiple single perceptrons (one for each output) are stacked parallel to each other. These perceptrons have the same input nodes, and activation functions, but each perceptron has separate weights. A feed-forward NN is a multilayer perceptron and uses weighted summation perceptrons. A multilayer perceptron contains more than one layer of multiple perceptrons, where the outputs of the current layer are used as the inputs of the next layer.
	
	NNs can only handle numerical inputs since the hidden layers are linear combinations of the input values. NNs also cannot handle missing valuesa, and are sensitive to noisy data. In theory NNs are robust to features with different scales, because the weights can be scaled for each feature accordingly. In practice, though, the weights are all initialised in similar ranges and if the optimisation algorithm finds a local minimum, features with larger scales can have too much influence on the output. NNs are also prone to overfitting because these models are very flexible and have many parameters.
	
	\subsection{Stochastic Gradient Descent}
	
	NNs have large amounts of amounts of weight parameters to estimate because of the interconnected multi-unit layers of linear units. Estimating these parameters is an optimisation problem that requires sophisticated approaches to estimate all the parameters simultaneously. There are several optimisation algorithms that have been used to estimate the parameters of NN models, such as batch gradient descent, stochastic gradient descent (SGD), conjugate gradient descent, and even metaheuristics. In this study, SGD is used across all models for consistency. SGD, as described in Algorithm~\ref{alg:sgd}, has two phases and updates the weights after each training instance passes though both phases. The first phase is a feedforward phase, during which, the error signal of every output and hidden unit is determined for a specific instance. The second phase, backpropogation, uses these error signals to update the weights. When every training instance has been passed through both phases, one training epoch is completed. The order in which the training instances are fed to the instances are processed by the algorithm is randomly shuffled before every epoch to prevent the model from learning a pattern from the order of the instances.
	
	\begin{algorithm}
		\caption{Stochastic Gradient Descent}
		\label{alg:sgd}
		\KwData{Training set $\mathcal{D}$, learning rate $\eta$, maximum epochs $T$}
		\KwResult{Trained weights $w_{k, j}$ and $v_{j, p}$}
		Initialize weights $w_{k, j}$ and $v_{j, p}$, and number of epochs $t = 0$\;
		
		\While{stopping conditions not met}{
			Randomly shuffle $\mathcal{D}$\;
			
			\For{each instance $p$}{
				
				Perform the feedforward phase to calculate values of hidden units $h_{j, p} \ (j = 1, 2, \ldots, J),$ and output units $o_{k, p} \ (k = 1, 2, \ldots, K)$\;
				
				Compute output error signals $\delta_{o_{k, p}}$ and hidden layer error signals $\delta_{h_{j, p}}$\;
				
				Perform backpropogation to adjust weights\;
			}
			$t \leftarrow t + 1$\;
			Update values for stopping conditions\;
		}
		
	\end{algorithm}
	
	\subsection{Active Learning}
	NNs are traditionally trained by optimising the weights using all the training instances to calculate errors, referred to as passive learning. Active learning, described in Algorithm~\ref{alg:active_learning} is different because the weights are updated using a subset of the training instances, and the gradually more instances are added to the training pool during training based on the informativeness of those instances. There are two approaches to active learning as described by Engelbrecht~(2001)~\cite{sasla}, incremental learning and selective learning. Incremental learning starts with a small subset of the candidate training set as the training set, and after each iteration, candidate instances based on informativeness is removed from the candidate set and added to the training set. Each candidate training set is a subset of all the previous candidate training sets. Selective learning in contrast starts with all the candidate instances in the training set, and after each iteration a subset of the original candidate set is selected based on some criterion.
	\begin{algorithm}
		\caption{Active Learning}
		\label{alg:active_learning}
		
		\KwData{Initial labelled set $\mathcal{L}$, unlabelled pool
			$\mathcal{U}$, number of iterations $K$, sampling size $B$}
		\KwResult{Trained weights $w_{k, j}$ and $v_{j, p}$}
		
		Initialize weights $w_{k, j}$ and $v_{j, p}$\;
		
		\For{$k \gets 1$ \KwTo $K$}{
			
			Perform one training epoch on $\mathcal{L}$\;
			Predict the outcome of each unlabelled instance, $\hat{y}_p, p \in \mathcal{U}$, using the current weights\;
			Compute informativeness scores $I_p, p \in \mathcal{U}$\;
			
			Select teh set, $\mathcal{S}$, of the $B$ observations with the highest informativeness scores\;
			
			Update labelled and unlabelled sets:
			$\mathcal{L} \gets \mathcal{L} \cup \mathcal{S}$, 
			$\mathcal{U} \gets \mathcal{U} \setminus \mathcal{S}$\;
			
			\If{$\mathcal{U} = \emptyset$}{
				\textbf{break}\;
			}
		}
	\end{algorithm}
	
	Sharma~and~Bilgic~\cite{alus} implemented active learning with uncertainty sampling (incremental learning method) for classification to determine the informativeness of instances. The idea is that the model is most uncertain about instances predicted close to the decision boundary, thus these instances are the most informative to include in the training pool. For binary classification the most informative instances will have a probability close to $0.5$., and for multiclass classification the most informative instances have small differences between the probabilities for different classes. The implementation proposed by Sharma~and~Bilgic~\cite{alus} is only applicable to classification because Regression models do not produce a decision boundary or probabilities. 
	
	Tsymbalov~\textsl{et al.}~\cite{dropoutsasla} proposed a method that performs uncertainty sampling for regression problems, where the neural network uses Monte Carlo-dropout. Dropout is a regularisation method where each hidden unit has a probability $\pi$ to be ignored during each training iteration. Dropout during training reduces the reliance on individual hidden units to reduces the chance of overfitting. Tsymbalov's proposed method uses dropout for predictions instead of training, because this results in non-deterministic predictions. The training instances not included in the current training pool, are predicted multiple times, and the variance of the predictions of each instance is used as the measure of informativeness. The variance of each instance is used as the uncertainty measure because instances with high variance in their predictions are heavily influenced by certain hidden units, thus these units are seen as uncertain.
	
	Engelbrecht~(2001)~\cite{sasla} developed the selective learning using sensitivity analysis (SASLA) approach to active learning. The idea of sensitivity analysis is instances that are highly sensitive to small changes in feature values are informative instances for training. Instances that are sensitive, are likely close to the decision boundary for classification problems. Sensitivity is determined based on first order derivatives of the output units with respect to the input features. The most informative  instances are those with the largest first order derivatives.
	
	\section{Methodology}
	The feed-forward NN is made up of perceptrons with the structure
	\[z = f\left( w_0 + \sum_{p = 1}^{P} w_p x_p\right),\]
	where $w_0$ is a bias term, $w_p$ is the weight of input $p$, and $f(z)$ is an activation function applied to the weighted sum. The outputs of the first layer of perceptrons (hidden layer),
	\[h_j = f_1\left(v_{j,0} + \sum_{p = 1}^{P} v_{j,p} x_p\right), j = 1, 2 , \ldots, J,\]
	become the inputs for the final layer that produces the outputs
	\begin{align}
		o_k &= f_2\left(w_{k,0} + \sum_{j=1}^{J} w_{k,j} h_j\right), \ k = 1,2,\ldots,K \\
		&= f_2\left(
		w_{k,0} +
		\sum_{j=1}^{J} w_{k,j}
		f_1\left(
		v_{j,0} + \sum_{p=1}^{P} v_{j,p} x_p
		\right)
		\right).
	\end{align}
	Both regression and binary classification models only have one unit in the output layer, and multiclass classification models have one unit for each class in the target variable. The outputs for classification problems are interpreted as probabilities, thus for binary classification if $o > 0.5$, the instance is assigned to class $1$, and otherwise assigned to class $0$. For multiclass problems, an instance is assigned to the class associated with the highest probability $o_k$. Cross entropy is used as the loss function for classification problems, defined as
	\[E = -\sum_{i=1}^{N} \sum_{k=1}^{K} (y_{i, k} \log o_{i, k}),\]
	where $y_{i, k}$ is the binary variable for whether observation $i$ is part of class $k$. The cross entropy for the binary case becomes
	\[E = -\sum_{i=1}^{N} (y_i \log o_i + (1 - y_i) \log (1 - o_i)).\]
	Fro regression tasks mean squared error (MSE) is is used as the loss function, defined as 
	\[E = \frac{1}{N} \sum_{i=1}^{N} (y_i - o_i)^2.\]
	
	The activation function $f_1$, applied to the hidden layer, adds flexibility to NNs, and the activation functions considered, are 
	\begin{align}
		\text{ReLU: } f(z) &=
		\begin{cases}
			z, & z \geq 0,\\
			0, & z < 0,
		\end{cases}\\
		\text{Leaky ReLU: } f(z,\alpha) &=
		\begin{cases}
			z, & z \geq 0,\\
			\alpha z, & z < 0,
		\end{cases}\\
		\text{ELU: } f(z,\alpha) &=
		\begin{cases}
			z, & z \geq 0,\\
			\alpha(e^z-1), & z < 0.
		\end{cases}
	\end{align}
	The activation function $f_2$ is used to format the output for a given task. For binary classification $f_2$ will be a sigmoid function defined as \[f_2(z) = \sigma(z) = \frac{1}{1+e^{-z}}.\] For multiclass classification $f_2$ will be a softmax function defined as \[f_2(z) = \frac{e^{z_j}}{\sum_{k=1}^{K} e^{z_k}},\] which is applied separately to each output. A linear function, $f_2(z) = z$, is used as the output activation function for regression tasks.
	
	\subsection{Stochastic Gradient Descent}
	\label{met:sgd}
	Before training, standardisation is applied to all input features using the training set, because NNs are sensitive to differences in scale of features. Standardisation is defined as 
	\[\tilde{x}_{i, p} = \frac{x_{i, p} - \bar{x}_p}{\sigma_p},\]
	where $\bar{x}_p$ is the average value of feature $p$ and $\sigma_p$ is the standard deviation of feature $p$. After standardisation the feed-forward NN is trained through SGD. The feedforward phase predicts all the training instances using the current weights, and these predictions are used to compute the training loss. After computing the loss, the weights are updated during the backpropogation phase using the current training loss. Backpropogation applies the chain rule to calculate the gradient of the loss with respect to the input variables. The chain rule is a method that simplifies the differentiation of nested functions, defined as
	\[\frac{\partial y}{\partial x} = \frac{\partial y}{\partial u} \frac{\partial u}{\partial x}.\]  The derivative of the loss with respect to the output layer is
	\[\delta_{o_k} = \frac{\partial E}{\partial o_k} f'_{2, k},\]
	where $f'_{2, k}$ is the first order derivative of the activation function of the output layer. The derivative of the loss with respect to the each hidden unit becomes
	\begin{align}
		\delta_{h_j}
		&= \sum_{k=1}^{K} \delta_{o_k}
		\frac{\partial o_k}{\partial h_j} \\
		&= \sum_{k=1}^{K} \delta_{o_k}
		w_{k,j} f'_{1,j}.
	\end{align}
	The derivatives of the loss with respect to the weights of the hidden layer are calculated as
	\[\delta_{v_{j, p}} = x_p \delta_{h_j}.\]
	The change of each weight of the output layer is 
	\[\Delta w_{k, j} = -\eta \delta_{o_k} h_j,\]
	and the change of each weight of the hidden layer is 
	\[\Delta v_{j, p} = -\eta \delta_{h_j} x_p.\]
	
	Momentum can be added to the update step to carry over changes from the previous update step $\Delta w_{k, j}^{(t-1)}$, which can speed up convergence. Weight decay shrinks the current weight to zero by a constant factor $\gamma \in [0, 1),$ when updating the weight, which reduces the influence of irrelevant and redundant features. When momentum of a constant factor $\lambda \in [0, 1)$ and weight decay ($\gamma$) are included the weights are updated as
	\begin{align}
		w_{k,j}^{(t)}
		&= \gamma w_{k,j}^{(t-1)}
		+ \Delta w_{k,j}^{(t)}
		+ \lambda \Delta w_{k,j}^{(t-1)}, \\
		v_{j,p}^{(t)}
		&= \gamma v_{j,p}^{(t-1)}
		+ \Delta v_{j,p}^{(t)}
		+ \lambda \Delta v_{j,p}^{(t-1)}.
	\end{align}
	
	Mini-batch learning, which is a method to reduce computaion time, is implemented during training. Instead of updating the weights after performing the feedforward and backpropogation phases for a single observation, with mini-batch learning the algorithm completes both phases for multiple instances before updating the weights. Mini-batch learning divides the training set into small subsets/batches, and then calculates $\Delta w_{j, k}$ for each instance in the batch and uses the average to update the weights.
	
	\subsection{Performance}
	\label{met:performance}
	Performance metrics are used to determine optimal hyperparameter setups and to compare different models. For classification tasks a model's accuracy, macro average F1-score and ROC-AUC score are recorded. The accuracy is an interpretable metric that indicates how frequently the predictions are correct, but high accuracy scores can hide problems such as high class imbalances. The F1-score of a class is the harmonic mean of the precision and recall scores of that class, and the macro F1-score is the average F1-score across all classes. Since the macro F1-score incorporates precision and recall, it reveals if the accuracy is simply high because of class imbalance and shows how well a model can predict every class. The ROC maps the true positive rate against the false positive rate of a specific class, across different probability thresholds. The area under the curve (AUC) indicates how frequently the true positive rate is higher than the false positive rate across the thresholds. IF the AUC $> 0.5$ then the true positive rate is higher more often than not, and this measures how likely it is for the model to assign a higher probability for the given class to instances that belong to that class than instances that do not belong to the class.  The primary metric for hyperparameter selection and comparison will be the macro F1-score and the secondary will be the AUC.
	
	For regression tasks a model's RMSE, MAPE and $R^2$ metrics are recorded. The RMSE is the square root of the MSE, which scales it to roughly the scale of the target values. The MAPE records absolute error, so larger deviations are not given steeper penalties like MSE, and it scales the error to a percentage, which makes the metric independent of the scale of the target values. The $R^2$ indicates how much of the variance of the target variable is captured by the model, and it is compared to the baseline of always predicting the mean. A perfect model has $R^2 = 1$ and if $R^2 < 0$ it means that the model performs worse than the baseline. Because the RMSE is directly related to the loss function, the primary metric used for comparison will be $R^2$. MAPE becomes unstable if some instances have target values at or very close to zero, therefore the secondary metric will be RMSE.
	
	\subsection{Hyperparameter optimisation}
	The hyperparameters for the NN model are tuned separately for each of the three activation functions considered using Bayesian optimisation. After the best hyperparameter set is found for each activation function, the CV performance metrics as specified in section~\ref{met:performance}, for a given task is calculated. The final hyperparameter set and activation function is chosen using the performance metrics. Bayesian optimisation generates random values for each hyperparameter within a specified range, then the model is trained using those hyperparameters. The validation loss of the trained model is used to compare different hyperparameter combinations, and the combination with the lowest validation loss is selected as the final set of hyperparameter values. The Bayesian optimisation algorithm learns which regions of hyperparameter values produce the lowest validation losses, and increases the probability of generating values in those regions, instead of performing a completely random search. 
	
	Cross validation (CV) is used to estimate the validation loss. With CV the training set is divided into $k$ sections (folds) and the model is trained $k$ times, and for each iteration fold $k$ is excluded from training and used as the validation set. The final estimate of validation loss, is the average of the loss calculated on the validation fold for each iteration.
	
	During training the model uses early stopping to prevent overfitting. Early stopping works by stopping the training procedure as soon as the loss calculated on a separate validation set fails to improve after a certain number of epochs.
	
	To reduce computation time pruning is implemented during hyperparameter tuning. The CV loss is tracked after each fold is completed for a trial, and then the CV loss is compared to other trials' CV loss after the same number of folds. If the CV loss is worse than the median of the previous trials, the trials is stopped and discarded.
	
	There are two hyperparameters that will be tuned for the model architecture (the number of hidden units and the activation function parameter). The NN model in this study only contains one hidden layer, so the number of units in that hidden layer is generated from values in the range $[32; 128] \in \mathbb{Z}$. It is assumed that values below 32 are likely to produce models that will underfit the data. A hidden layer with 128 units already requires $128 (P+1) + 129K$ parameters to determine by the training algorithm, so the ceiling is set at 128 to prevent the models from becoming very large. The leaky ReLU and elu activation functions have a parameter $\alpha$ that will also be tuned alongside other hyperparameters. For leaky ReLU the range of $\alpha$ is $(0.001; 0.3)$.
	
	For the SGD algorithm three hyperparameters require tuning (learning rate, momentum, and weight decay). The learning rate is selected from a range of $(10^{-5}; 10^{-2})$ for classification and $(10^{-5}; 10^{-3})$ for regression. Both classification and regression models can have exploding gradients if the learning rate is too high, where the weights grow uncontrollably to very large values. The distinction between classification and regression is because the regression NN uses a linear activation function, while the classification activation functions force the outputs to be in the range $(0; 1)$. Very small learning rates can still be effective because the weights are updated very frequently (after each mini-batch). The momentum is selected from a range of $[0; 0.5)$ because larger momentum values can lead to unstable weights if the learning rate is also relatively large. The weight decay is selected from a range of $(10^{-6}; 10^{-2})$, which spans from very weak regularisation to moderately strong regluarisation. Both the learning rate and weight decay are sampled from a logarithmic-uniform distribution, because they span multiple orders of magnitude. The logarithmic-uniform distribution sample small values more frequently than large values, which is useful because for larger values small differences have very little impact on the model.
	
	\subsection{Active learning with uncertainty sampling}
	During active learning the candidate instances are repeatedly added to the training set until all candidate instances have been added to the training set. Measuring the uncertainty of instances for classification is straightforward because th output already provides probabilities for each class. One measure of uncertainty described by Sharma~and~Bilgic~\cite{alus}, is cross entropy:
	\[\boldsymbol{x}^* = \operatorname*{argmax}_{\boldsymbol{x}_i \in D_u} \{-\sum_{k = 1}^{K} o_{i, k} \log o_{i, k},\}\]
	where $\boldsymbol{x}^*$ is the most uncertain instance in the set of candidate instances $D_u$. Another method is using the maximum conditional probability:
	\[\boldsymbol{x}^* = \operatorname*{argmax}_{\boldsymbol{x}_i \in D_u} \{ 1 - \max_{k} o_{i, k}\},\]
	and a third method is to use the margin of confidence:
	\[\boldsymbol{x}^* = \operatorname*{argmax}_{\boldsymbol{x}_i \in D_u} \{ \max_{k} o_{i, k} - \min_k o_{i, k}\}.\] For binary classification all three methods result in the same order of uncertainty, because maximum each of these can be is when $o_i = 0.5,$ the margin of confidence is implemented in this study. For multiclass classification the cross entropy is used to measure uncertainty in this study. 
	
	The uncertainty measure for regression problems is more complicated to determine because there is no decision boundary to base uncertainty on. The method proposed by Tsymbalov~\textsl{et al.}~\cite{dropoutsasla} is performed by predicting the output $R$ times to determine $o_i^{(1)}, o_i^{(1)}, \ldots, o_i^{(R)},$ and then rank the instances with
	\[
	\boldsymbol{x}^* = \operatorname*{argmax}_{\boldsymbol{x}_i \in D_u} \sum_{r=1}^{R} \frac{1}{R-1}\left( o_i^{(r)} - \bar{o}_i\right)^2, 
	\] 
	and \[\bar{o}_i = \frac{1}{R} \sum_{r=1}^{R} o_i^{(r)}.\] Each time the training set is updated, a set number of instances are added based on the ranking.
	
	\subsection{Selective learning using sensitivity analysis}
	For SASLA the first order derivatives of the outputs with respect to the input variables are calculated each iteration. These derivatives are used to determine which candidate instances should be included in the training set. The first order derivatives are calculated in the same manner that the derivatives with respect to the weights for SGD (section~\ref{met:sgd}), where the derivative of output $k$ with respect to feature $p$ is 
	\[
	\begin{aligned}
		S_{o_k,p}
		&= \sum_{j=1}^{J}
		\frac{\partial o_k}{\partial h_j}
		\frac{\partial h_j}{\partial x_p} \\
		&= f'_{2,k} \sum_{j=1}^{J}
		w_{k,j} f'_{1,j} v_{j,p}.
	\end{aligned}
	\]
	These derivatives form the sensitivity matrix for each observation, and the final sensitivity measurement for instance $i$ is a norm applied to the sensitivity matrix. In this study the maximum-norm is used, but Engelbrecht~(2001)~\cite{sasla} also specified that the Euclidean-norm and sum-norm could be used. The sensitivity of instance $i$ is therefore \[\Phi^{(i)} = \max_{k=1, 2, \ldots, K; p=1, 2, \ldots, P} \left\{\left|S_{o_k,p}\right|\right\},\] and the candidate instances are  ranked as \[\boldsymbol{x}^* = \operatorname*{argmax}_{\boldsymbol{x}_i \in D_u} \left\{ \Phi^{(i)}\right\}.\]
	
	All instances that are sufficiently sensitive are included in the training set for the next iteration. The threshold used in this study is 
	\[
		t = \beta \cdot \text{median} \left\{ \Phi^{(1)}, \Phi^{(2)}, \ldots, \Phi^{(N)}\right\},
	\], thus all instances such that $\Phi^{(i)} > t$ are included. The value $\beta \in [0, 1)$ is a fixed parameter chosen beforehand.

	\section{Empirical Procedure}
	The empirical procedure descirbes the steps followed to perform the exerpiments for every classification and regression problem. Only the Student Dropout and Academic Success dataset and the Seoul Bike Sharing Demand dataset are preprocessed as described in section~\ref{met:data}. After preprocessing the dataset is split into a training set, which is also used as the candidate set and a test set. The test set contains 20\% of the observations and a seed of 51 is used to split the data.
	
	\subsection{Hyperparameter tuning}
	For hyperparameter tuning the training set is divided into five folds using a seed of 42. Five folds are used because more folds dramatically increase the runtime of the tuning algorithm. For each fold in CV the input features are standardised based only on the mean and standard deviation of the training instances of that fold to avoid data leakage. For each fold 15\% of the training instances are held separate as validation for early stopping with a patience of 10 epochs. The model is trained for a maximum of 75 epochs because for most of the datasets the model is already close to converging after 75 epochs. A mini-batch size of 32 is used because it provides a good balance between convergence and efficiency. The hyperparameters are tuned by performing 80 trials of the Bayesian optimisation algorithm with pruning. After the 80 trials are complete the parameter set that produced the lowest CV loss.
	
	The Bayesian optimisation algorithm is repeated three times using each of the specified activation functions for the hidden layer. The same training procedure is performed with the same seeds on the best hyperparameters found for each activation function and CV performance metrics in section~\ref{met:performance} are used to compare the results and select the activation function and final hyperparameters.
